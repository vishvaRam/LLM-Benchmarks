• Endpoint Specification: How /v1/systemone Works ∨

The /v1/systemone endpoint answers a set of typed questions about a state and returns a probability for every allowed answer.

1. Execution Read

Each question is one read. The user message is the state, followed by the question, its options with type labels, and an instruction to answer with one label.

2. Single-Token Read

The read evaluates the reply's first token. Each label must be exactly one token, or the endpoint returns HTTP 400.

3. Label Mass & Softmax

Returns logprobs of question label tokens. Softmax over labels gives probability. Requires --logprobs-mode raw_logprobs or processed_logprobs.

4. Prefix Caching Optimization

With --enable-prefix-caching, the state is prefilled once and each subsequent question prefills only its own text, then reads one token.
